AUTOLOOT COMPATIBILITY CHECK

This tool only reads ACOdyssey.exe. It does not start or modify the game,
install a hook, or change any game files.

1. Copy these three files next to ACOdyssey.exe:
   AutoLootCompatibilityCheck.exe
   Run_AutoLoot_Compatibility_Check.bat
   README.txt
2. Double-click Run_AutoLoot_Compatibility_Check.bat.
3. Send AutoLootCompatibilityReport.txt to the AutoLoot author.

Do not send or upload ACOdyssey.exe.

The report does not make a new game build supported automatically. A separate
test build and an in-game test are required after its results are reviewed.
